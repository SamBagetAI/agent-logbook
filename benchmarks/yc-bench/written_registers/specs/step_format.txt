The Register gets one step per decision.
- step["action"]: {"tool": "run_command", "arguments": {"commands": [...]}}, every command the agent ran at its previous decision, in order (an empty list when it ran none; None at the first decision).
- step["result"]: a JSON string, a list of {"command": ..., "output": ...}, one per command, in the same order. Each output is the tool's result as a JSON string: {"ok", "exit_code", "stdout", "stderr"}; stdout holds the command's own JSON.
- step["seen"]: the user message of this decision (see <example_step> and prompt.py).
